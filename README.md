# Interactive Spider Clock

An interactive Spider Clock desktop application built with Python and `tkinter` featuring a spider centerpiece whose legs form the clock hands, rotating pastel mandala gears in the background, a vertical silk thread from the top, and toggleable per-second tick-tock sound effects.

## Features
- **Real-Time Clock**: Displays accurate hours, minutes, and seconds synchronized with your system time.
- **Spider Leg Hands**: Black-and-red spider design where extended front legs act as the hour and minute hands alongside a second hand.
- **Rotating Mandala Gears**: Subtle pink floral/cog gear patterns rotating in the background.
- **Tick-Tock Sound & Mute Toggle**: Plays per-second tick-tock audio with an on-screen `Tick: ON / OFF` button.
- **No External Packages Needed**: Uses Python's built-in modules (`tkinter`, `math`, `time`, `threading`, `platform`, and `winsound`).
